## Codebase Patterns
- Rust models use serde::{Deserialize, Serialize} for Tauri IPC
- DetectionSource uses #[serde(rename = "snake_case")] for JSON serialization
- Commands use spawn_blocking for async operations that run shell commands
- Frontend services wrap Tauri invoke() calls with typed TypeScript interfaces
- Tests in src-tauri/tests/ are integration tests using #[test]
- PEST grammar: Use simplified flat rules for directives, parse content details in Rust code
- ZigDirective enum uses `#[serde(tag = "type", rename_all = "snake_case")]` for proper JSON serialization with tagged variants
- Parser tests go in `src/parser/mod.rs` under `#[cfg(test)] mod tests`
